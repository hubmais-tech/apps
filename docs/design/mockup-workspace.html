Aula 7 · Calendário editorial na prática

Módulo 3 · Produção 12 minIntermediário 2 materiais
4:35 / 12:00Módulo 3 de 5 · 74% do curso

Nesta aula você monta o calendário editorial de uma semana para um negócio real de Aracaju. A ideia é sair da teoria: ao final, você terá um arquivo pronto para usar no desafio do módulo.

O que você vai fazer

  • Definir 3 pilares de conteúdo para a marca escolhida.
  • Distribuir 7 postagens entre feed, stories e reels.
  • Escrever a legenda e a chamada de um dos posts.
Desafio desta semana vale para o portfólio

Entregue até sexta, 21/11. A Ana Souza devolve o feedback em até 3 dias úteis.
